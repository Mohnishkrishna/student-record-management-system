Student Record Management System
About the Project

The Student Record Management System is a simple GUI-based database application developed using Python, Tkinter, and SQLite. It helps users manage student information efficiently.

Features
Add new student records
View all student records
Search students by ID, name, or course
Update student details
Delete student records
Store data in an SQLite database
Validate user input
Technologies Used
Python
Tkinter
SQLite
SQL
Requirements
Python 3.x
Tkinter
SQLite3

Tkinter and SQLite3 are included with most standard Python installations.

How to Run
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:

python student_management.py

The application window will open, and the database will be created automatically.
Database

The application creates a students.db file to store student records.

Learning Objectives
GUI development using Tkinter
Database connectivity using SQLite
SQL CRUD operations
Input validation and record searching
